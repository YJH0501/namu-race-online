# 문서 후보 확장: 15,199 → 100,000

## 데이터와 한계

이것은 최신 유효 문서 10만 개를 전수 검증했다는 뜻이 아니라, **추첨 후보가 10만 개**라는 뜻이다. 힌트 유무로 후보를 제한하지 않는다. 문서 원문과 이미지는 기존 방식대로 읽는다.

고정된 공개 과거 데이터 867,024행을 검사했다. 과거 리다이렉트 295,647행, 일반 문서 링크가 검출되지 않은 9,165행, 제목 기준 미달 3행, 짧은 문서 9행을 제외해 562,200행을 확보했다. 해당 시점의 문서 내용 기준이다. 일반 문서 링크 검출은 최소한의 구조 검사이며 실제 목표까지의 도달 가능성 증명이 아니다.

제목 처리 호환성·중복·관리 이름공간 검사를 추가하고 전체 후보를 SHA-256 고정 순위로 정렬해 일부를 선택했다. 가나다순 첫 10만 개를 자르지 않았다. 기존 2026-09-04 내부 링크 목록을 우선 유지하고 알려진 현재 오류만 정리했다. 과거 자료의 제목·텍스트·이름공간만 처리했으며 기여자 데이터는 읽거나 배포하지 않았다. 본문은 필터 검사에만 사용하고 저장하지 않는다.

## 현재 원문 표본 검사

최초 목록에서 고정 시드로 신규 80개·기존 20개를 뽑아 기존 웹 리더로 각 1회 읽었다. 이는 계층별 표본이며 100개 결과를 전체 목록의 정확한 오류율로 해석하면 안 된다.

| 표본 | 확인 수 | 같은 제목으로 응답 | 일반 문서 링크 검출 |
| --- | ---: | ---: | ---: |
| 신규 후보 | 80 | 65 | 65 |
| 기존 후보 | 20 | 19 | 19 |

7개는 최신 제목이 달랐고 9개는 불러오지 못했다. `server/data/catalog-corrections.json`에 제목 보정/제외를 기록하고 후보를 보충했다. 원래 결과는 `catalog-live-sample-2026-09-07.json`에 그대로 보존한다. 보정 후 같은 표본만 다시 검사한 결과를 독립적인 성공률로 제시하지 않는다. **검사하지 않은 후보에는 현재 삭제되었거나 제목이 바뀐 문서가 남아 있을 수 있다.**

최신 정식 제목으로 바꾼 7개는 해당 정식 주소를 별도로 읽었을 때 모두 HTTP 200과 정확한 제목을 확인했다. 이는 보정 검증이지 추가 무작위 표본 결과가 아니다.

원문 요청은 표본에 한정하고 최대 12초·2MiB, 요청 사이 600ms 대기, 접근 거부(403/429) 시 중단하도록 했다. 차단된 원문 우회나 전체 나무위키 크롤링은 하지 않는다.

## 게임 동작

- 랜덤·라운드 출발과 목표, 새 일일 목표가 같은 서버 목록을 사용한다. 일일 출발은 기존 목록 유지.
- 대기실에는 출발·목표를 숨기며 시작 후 모든 참가자에게 같은 제목을 공개한다.
- 추첨은 배열 인덱스를 무작위로 선택하고 최근 제목을 제외한다. 정상 경로에서 10만 항목 전체를 복사·필터링하지 않는다. 제외 항목이 대부분인 경우에도 제한된 시도 후 종료 가능한 대체 절차를 사용한다.
- 기존 방에 저장된 경로와 기록은 수정하지 않는다. 웹이나 EXE 배포 파일을 바꿀 필요 없이 게임 서버만 업데이트한다.
- 실시간 접속 유지·점수·힌트·원문 표시 기능은 이번 변경 범위에 포함하지 않는다.

## 재생성 / 검사

`duckdb==1.5.5`는 데이터 준비 도구에만 필요하며 게임 실행 의존성이 아니다.

1. `python scripts/prepare-title-index.py` — 고정 공개 Parquet에서 로컬 색인 생성.
2. `node scripts/build-title-catalog.mjs` — 기존 판, 색인, 최신 보정을 이용해 10만 개와 출처·해시 기록 생성.
3. `npm run check`와 서버 TypeScript 검사.
4. `node test/integration-catalog.mjs`, `node test/integration-hints.mjs`, `node test/integration-document-hints.mjs`.

현재 소스 표본 검사는 선택적 네트워크 작업이다. `node scripts/check-title-catalog.mjs`는 기존 결과 파일 덮어쓰기를 거부한다. `NAMU_CATALOG_SAMPLE_OUTPUT`에 새 출력 경로, 독립 표본은 `NAMU_CATALOG_SAMPLE_SEED`에 새 시드를 지정한 뒤 실행한다.
