# v0.4.7-beta.1 — 나가기 확인, 리다이렉트 힌트, 웹 재접속

- 웹과 EXE의 완주·포기 후 첫 화면으로 돌아가기 전에 확인합니다. 취소하면 결과와 펼친 경로를 유지합니다.
- 목표가 나무위키의 다른 제목으로 넘겨주기되는 경우, 원본 사이트의 HTTP 리다이렉트를 최대 5회 확인한 후 실제 문서에서 힌트를 가져옵니다. 목표 이름과 레이스 경로·승리 판정은 바꾸지 않습니다.
- 힌트 출처는 실제 문서 제목으로 표시합니다. 외부 사이트, 반복 리다이렉트, 제목만 다른 무관한 본문, 접근 거부 응답은 허용하지 않습니다.
- 웹에서 재접속 조회가 한 번 실패했다는 이유만으로 저장된 참가 정보를 지우던 문제를 수정했습니다. 일시적인 오류는 참가 정보를 유지하고 재시도하며, 실제 만료는 구분해서 안내합니다.
- 응답이 멎은 웹 연결을 재연결하고, 탭·네트워크로 돌아오면 바로 방 상태를 확인합니다. 이전 연결의 늦은 응답은 새 연결을 덮어쓰지 못합니다.

검증: 웹 회귀 테스트 6개, 서버·EXE 단위 테스트 47개, 접속 유지·힌트 투표 통합 테스트, 숨겨진 EXE 테스트 창에서 취소/확인 동작, 웹 빌드와 타입 검사. 실제 원본의 JIT 컴파일 → JIT, 슈퍼주니어-T → SUPER JUNIOR-T, 채태인/2018년 → 채태인/선수 경력/2018년에서 힌트 추출을 확인했습니다.

웹 이탈 원인 분석: 일시적인 재접속 조회 실패로 참가 정보가 삭제되는 코드 경로는 재현했습니다. 친구의 실제 이탈 시점 로그가 없으므로 모든 이탈의 원인을 이것으로 단정하지 않습니다. 기기 절전·브라우저 중단 등으로 2분 넘게 통신이 없는 경우에는 기존 서버 접속 만료 정책이 적용됩니다. 일반적인 탭 전환만으로 곧바로 퇴장시키지는 않습니다.

접근 거부·삭제 문서·힌트로 쓸 설명이 없는 문서까지 모두 해결하는 변경은 아닙니다. 기존 실패 힌트의 임시 저장은 최대 5분 뒤 갱신됩니다.

공개 검증 (2026-09-08):
- 웹 버전 18이 공개 페이지에 반영됐으며 검증한 파일과 배포 파일이 일치합니다.
- 실제 공개 방 2개에서 JIT 컴파일·슈퍼주니어-T의 리다이렉트 힌트가 두 참가자에게 동일하게 표시됐습니다. 원래 목표 이름은 유지됐으며, 준비 요청 응답에는 미공개 본문이 포함되지 않았습니다. 테스트 방은 정리했습니다.
- 공개 서버의 접속 유지·2라운드 경로·결과 보존 회귀 검사도 통과했습니다.
