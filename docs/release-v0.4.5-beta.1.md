# 나무레이스 온라인 0.4.5-beta.1

- 목표를 힌트 카드 64개로 제한하던 조건 제거: 랜덤·라운드·일일 목표가 15,199개 제목 스냅샷을 사용합니다.
- 카드 없는 목표도 과반수 투표 후 나무위키 분류·본문 설명을 자동 준비하고 서버에서 재사용합니다.
- 분류 → 짧은 설명 순서이며, 설명이 없으면 빈 2단계를 제공하지 않습니다. 일부 문서는 원문 접근/제목 불일치로 힌트가 제공되지 않을 수 있습니다.
- 웹·프로그램 참가자에게 같은 힌트를 공개하며, 다음 라운드의 힌트와 섞이지 않도록 보호했습니다.
- 기존 카드, 60:40 라운드 점수, 전용 뒤로가기, 이탈 참가자의 결과·경로 보존은 유지합니다.

웹은 새로고침, Windows 설치형은 앱 내 업데이트 확인 → 다운로드 → 업데이트 후 다시 시작으로 적용하세요.

macOS universal DMG는 Apple Developer ID 서명·공증을 받지 않았습니다. 이번 변경이 기존 Mac 실행 문제를 해결했다고 보장하지 않습니다. Mac은 웹에서 Windows 프로그램 참가자와 같은 방을 이용할 수 있습니다.

100개 표본에서 분류/설명 91개를 확보했으나 모든 나무위키 문서의 성공률이나 정확도를 보장하는 수치는 아닙니다. 자세한 실험 결과와 한계는 저장소의 힌트 평가 보고서를 참고하세요.
