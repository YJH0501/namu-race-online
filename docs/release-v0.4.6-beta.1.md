# v0.4.6-beta.1 — 접속 유지 및 라운드 결과 안정화

- 짧은 통신 지연으로 참가자가 제거되지 않도록 접속 유예를 2분으로 조정했습니다. 인증된 방 조회와 게임 조작도 접속 상태를 갱신합니다. 명시적인 방 나가기는 즉시 반영됩니다.
- EXE는 게임 조작마다 연결을 새로 만들지 않고 기존 연결을 유지합니다. 백그라운드 창의 접속 확인 타이머를 유지하고, 응답이 멎은 연결은 재연결합니다.
- EXE 결과 화면은 다른 참가자의 이동에 맞춰 필요한 내용만 갱신합니다. 열린 자세히보기와 결과 화면의 노드를 유지합니다.
- 웹과 EXE 모두 2라운드 이후 방금 완주한 라운드 경로를 즉시 표시합니다. 모두 끝내기 전에는 '점수 집계 대기'로 표시하고, 집계되면 확정 점수로 바뀝니다.
- 아직 게임 중인 참가자에게 다른 플레이어의 경로는 공개하지 않습니다.

퇴장 재확인과 리다이렉트 힌트는 이번 변경에 포함하지 않았습니다.

검증: 대기실·레이스·관전·라운드 대기·최종 결과의 접속 유지, 인증 실패 시 갱신 거부, 실제 이탈 및 기록 보존, 3라운드 API 통합 테스트, 숨겨진 EXE 테스트 창에서 결과 노드·자세히보기 유지와 연결 재사용, 웹 라운드 경로 단위 테스트. 일반·힌트·문서 목록 회귀 검사와 공개 배포 후 확인도 수행합니다.
