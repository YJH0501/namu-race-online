# 준비된 힌트 카드

현재 검토된 카드 64개는 빠른 제공용으로 유지합니다. v0.4.5부터 목표 목록을 제한하지 않으며 카드가 없는 목표는 자동 준비 힌트를 사용합니다. 랜덤 출발과 목표는 기존 15,199개 제목 스냅샷을 사용합니다. 전체 나무위키나 두 문서 간의 이동 가능성을 검증한 데이터는 아닙니다.

- 1단계: 제목이 정확히 일치하는 한국어 위키백과 문서의 짧은 설명. 발음·번역 괄호 등을 생략·정리했습니다.
- 2단계: 같은 문서 도입부의 본문 링크 중 기존 나무위키 제목 스냅샷에도 있는 2~3개 연관 개념. 나무위키 직접 링크/최단 경로를 보장하지 않습니다.
- 후보 수집 후 설명이 불명확하거나 품질이 낮은 항목을 제외했습니다. 위키의 편집이나 오류가 이후 바뀔 수 있으므로 카드 확장 시 다시 검토해야 합니다.
- 이 목록은 목표 선정에 영향을 주지 않습니다. 기존 방의 경로는 유지합니다. 카드 없는 목표는 과반수 투표 후 원문 분류·설명을 준비하며, 자료를 확보하지 못할 수 있습니다.
- 카드는 `sourceUrl`, `sourceTitle`, 연관 개념 도입부의 `sourceRevision`, 준비 시점과 라이선스를 보존합니다. CC BY-SA 4.0, 위키백과 기여자 출처. 전체 원문·이미지는 저장하지 않습니다.

## 확장 절차

유지보수자가 명시적으로 `node scripts/prepare-hint-cards.mjs`를 실행하면 후보 JSON을 stdout으로 출력합니다(`--base64` 지원). 게임 실행·빌드·CI는 이 스크립트를 실행하지 않습니다. API 접근 거부(403/429)는 중단하고 우회하지 않습니다.

후보는 자동 승인하지 않습니다. 원문과 설명, 제목의 의미 일치, 연관성, 글자 깨짐, 잘못된 편집을 검토하고 승인한 항목만 `reviewed: true`로 표시해 `hint-cards.json`에 반영합니다. 버전·준비 시점을 갱신하고 `npm run check`와 `node test/integration-hints.mjs`를 통과시킨 뒤 서버를 배포합니다. 프로그램 재설치 없이 새 방부터 추가 카드를 사용합니다.

`shared/prepared-hints.mjs`가 라운드의 비공개 스냅샷을 Durable Object에 보관합니다. 공개 전에는 설명·연관 개념·출처를 API/WebSocket에 싣지 않습니다. 준비된 64개 카드는 외부 요청 없이 즉시 공개하지만 자동 준비 힌트는 Sites 서버 소유 캐시를 읽으며 외부 요청 0회를 보장하지 않습니다. 2단계는 1단계 이후 60초 및 새 과반수 투표가 필요합니다.
